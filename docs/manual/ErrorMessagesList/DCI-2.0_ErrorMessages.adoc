== はじめに

本書は、DCI-2.0コントローラの各要素(DCI物理インフラ, DCIマネージャ, DCIテナント論理インフラ)が出力するエラーメッセージの一覧を示したものです。
システム内で使用しているOSS(Open Source Software)が出力するエラーメッセージは対象外になります。


== DCI物理インフラ(dci_physical_infrastructure)が出力するエラーメッセージ一覧
DCI物理インフラは5つのコンポーネント(cdi, exporter, log, maas, network)で構成されている。各コンポーネントが出力するエラーメッセージを以下に示す。
