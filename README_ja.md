# DHRC: Dynamic Hardware Resource Controller 概要

DHRCは、分散コンピューティングリソースを柔軟かつ効率的に管理・制御するためのオープンソースソフトウェアです。IOWN時代に求められる省電力・低遅延・高柔軟性を実現する次世代アーキテクチャDCI (Data-Centric Infrastructure) の中核機能として設計されています。

# DCI: Data-Centric Infrastructure 概要
DCIでは、以下の課題解決を目的としています。
* 電力消費の増大：AIなど大量データ処理による電力負荷を低減
* コストパフォーマンス低下：ハードウェア構成の最適化による設備費・運用コスト削減
* 柔軟性不足：顧客ニーズに応じた迅速な構成変更とサービス開発を支援

DCIに関する詳細情報については、以下のリソースを参照してください。

参考リンク：[IOWN実用化に向けたData-Centric Infrastructure (DCI) の技術開発の取り組み](https://journal.ntt.co.jp/article/33807)

# 目指している提供価値

以下の4つの価値の提供を目指してます
1. アクセラレータの有効活用: GPUや専用ハードウェアを効率的に利用し、性能要件を満たす
2. ハードウェア構成の最適化: CDI (Composable Disaggregated Infrastructure) 技術を活用し、ニーズに応じて柔軟に構成変更
3. アプリ配備の最適化: スケジューリングにより、リソースの最適配置を実現
4. アプリ開発の容易化: Kubernetesベースのアプリ実行環境を標準化し、迅速なサービス開発・運用を支援

# 主要機能
|機能|説明|
|:--|:--|
|リソースプール管理機能|クラスタ管理機能からの要求に基づき、HWリソースプールから適切なアクセラレータをもつサーバを柔軟に構成​|
|クラスタ管理機能|複数テナントが独立してアプリを実行可能なクラスタの構築、およびスケールに応じたクラスタ構成の動的変更​|
|スケジューラ機能|アプリのデプロイ・削除と、アプリに対するHWリソースの割当てを制御|
|通信管理機能|アプリ間の通信に必要な情報を提供し、RDMAによるCPU非介在なアプリ間データ転送を管理|

# DHRCの構成
DHRCは、DCIマネージャ、DCI物理インフラ、DCIテナント論理インフラの3要素で構成されています。

<img src="./docs/_image/Architecure_ja.png" width="900px" alt="構成図">

|要素|説明|主な機能|
|:--|:--|:--|
|DCIマネージャ|DCI物理インフラおよび DCIテナント論理インフラを統合的に管理する中核コンポーネント| <ul><li> DCIテナント論理インフラ構築 </li> <li> リソース管理 (論理サーバ、物理サーバ・カード・ネットワーク機器、コントローラやアプリのイメージ管理) </li> <li> システム全体のメトリクス／ログ収集・障害検知・通知・障害対応 </li> <li> システム全体のバックアップ・リカバリ管理・メンテナンス</li></ul> |
|DCI物理インフラ|リソースプール (COTSサーバ群・CDI デバイス・物理 NW) および管理コントローラから構成される物理基盤|  <ul> <li> 物理リソース管理・リソース払出・返却 </li> <li>  物理インフラのメトリクス／ログ収集 </li> <li> 物理インフラのバックアップ・リカバリ管理・メンテナンス </li> </ul> |
|DCIテナント論理インフラ|DCIアプリの実行環境、およびテナント共通で利用される論理的管理機能を提供| <ul> <li> DCIアプリ実行環境の提供 (Pod管理・接続機能・監視機能) </li> <li> テナント管理 (ユーザ管理・ポリシ管理) </li> <li> テナントやアプリのメトリクス／ログ収集・監視基盤・障害検知・通知・障害対応 </li> <li> テナントのリソーススケーリング </li> <li> テナントのバックアップ・リカバリ管理・メンテナンス </li> </ul> |
|DCIアプリ|テナント運用者によって構築・運用されるアプリケーション (DHRC外)||

# リポジトリ構成

|リポジトリ|説明|
|:--|:--|
|[dci_common](https://github.com/openkasugai/dci_common) <br>(本リポジトリ)|DHRC のメインリポジトリです。DHRC を構成する各コンポーネントのサブリポジトリを参照するとともに、DHRC の構築・運用に必要なマニュアルやスクリプト、I/F 実装例としてのスタブコードを格納します。|
|[dci_manager](https://github.com/openkasugai/dci_manager)|DCIマネージャのコードを格納します。例えば、ClusterAPI用の独自プロバイダ機能、リソースプール管理機能、構成管理DB、構成品配備スクリプト、外部OSS用のファイルがあります。|
|[dci_physical_infrastructure](https://github.com/openkasugai/dci_physical_infrastructure)|DCI物理インフラのコードを格納します。例えば、MAAS管理機能、CDI管理機能、NW機器管理機能、外部OSS用のファイルがあります。|
|[dci_tenant_infrastructure](https://github.com/openkasugai/dci_tenant_infrastructure)|DCIテナント論理インフラのコードを格納します。例えば、DCIアプリ間の接続機能、監視基盤、リソーススケーリング機能、外部OSS用のファイルがあります。|
